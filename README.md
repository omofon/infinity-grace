## Deployment

### Deploy to Vercel
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → New Project → Import your repo
3. Vercel auto-detects static HTML — no configuration needed
4. Click **Deploy**

Or via Vercel CLI:
```bash
npm i -g vercel
cd infinity-grace-proposal
vercel
```

### Deploy to Netlify
1. Drag and drop the `infinity-grace-proposal` folder to [netlify.com/drop](https://app.netlify.com/drop)
2. Or connect your GitHub repo via Netlify dashboard

### Deploy to GitHub Pages
1. Push to a GitHub repository
2. Go to Settings → Pages → Source: `main` branch, root folder `/`
3. Your site will be live at `https://yourusername.github.io/repository-name`
